# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x | Yes |
| 1.x | No: upgrade (see [docs/migration-v1-to-v2.md](docs/migration-v1-to-v2.md)) |

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through GitHub:
**Security** tab → **Report a vulnerability** (private vulnerability reporting).

Please include the affected version, a description, steps to reproduce, and the impact you expect. You
will get an acknowledgement within 7 days and a fix or a mitigation plan as soon as the issue is
confirmed. Credit is given in the release notes unless you prefer otherwise.
